## 🚀 Project Overview
**Calculator Master** is an advanced, menu-driven Python application developed as part of the midterm summative assessment. It demonstrates industry-standard version control practices—including isolated feature branches, pull request peer reviews, iterative commit histories, and rigorous input validation—all executed and verified inside a secure Linux Virtual Machine environment.

## 🗂️ Git Branch Architecture
The project follows a strict branching strategy, ensuring all features are developed independently before being merged into `main` via Pull Requests:

```text
main (Final Integrated Application)
├── addition_Albay       (Addition feature & numeric validation)
├── subtraction_Albay    (Subtraction feature & numeric validation)
├── multiplication_Albay (Multiplication feature & numeric validation)
└── division_Albay       (Division feature, validation, & zero-division handling)
